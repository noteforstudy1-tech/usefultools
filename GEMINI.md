# Arcade Hub: Connect 4, Tic Tac Toe & Dots and Boxes

This directory is the primary workspace for Raghav Parashar's Arcade Hub, a collection of classic board games with modern features.

## Live Status
- **URL:** https://noteforstudy1-tech.github.io/usefultools/
- **Repo:** https://github.com/noteforstudy1-tech/usefultools
- **Branding:** Made by Raghav Parashar

## Games Included
1. **Connect 4 Pro:** The classic 7x6 strategy game.
2. **Tic Tac Toe:** Standard 3x3 game with an unbeatable AI.
3. **Dots & Boxes:** Strategic 5x5 grid game with box-capture logic.

## Key Features
- **Smarter AI:** Minimax algorithm with Alpha-Beta pruning (Hard/Medium/Easy modes).
- **Online Multiplayer:** Global play via Peer-to-Peer connectivity (PeerJS).
- **Visual Overhaul:** Modern "Glassmorphism" UI with smooth transitions and win animations.
- **Scoreboard:** Unified session tracking for wins and draws across all games.
- **Undo Feature:** Full move history support to refine strategies.
- **Dedicated Audio:** Background music (`coolbgmusic.mp3`) with play/pause and volume controls, plus layered SFX.

## Technical Notes
- **Hosting:** GitHub Pages.
- **Multiplayer Protocol:** PeerJS (raghav-[ID] namespace).
- **Responsive:** Optimized for Desktop, Tablet, and Mobile.
